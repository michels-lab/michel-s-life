# Granada — recovery and clock-safe personal alarms

Old expired one-shot rows without a future occurrence no longer block an unrelated edit; only unchanged old rows may be disabled automatically. Boot/clock recovery retains expired one-time rows as inactive rather than ringing missed events retroactively. Clock/timezone changes re-arm personal alarms only, leaving the canonical Focus timer unchanged. Deleted IDs cannot be reopened from retained delivery markers. Snooze now stages the new OS occurrence before one preference commit acknowledges the original delivery and persists the replacement, reverting staged intent on failure. No automatic retroactive delivery, no UI redesign, no claim of AlarmManager atomicity across process death or disk failure. Structural regressions added.
