# Michel's Life — Windows v3.0.217 + Android Direct v0.2.5

One unified public release with a Windows installer and portable build plus an Android Direct APK using the established permanent signing certificate.

## Android v0.2.5 / versionCode 7
- Full touch-first Mission editing with mission name, description, options and seven weekly recurrence days.
- 44px-class touch controls; Android-owned edit sheet with independent scrolling, keyboard-sized inputs, reachable sticky Save/Cancel.
- Persists using the canonical shared Desktop/Android mission state, without a duplicate Android store.
- Preserves the existing Android Dashboard, Focus, Calendar, Journal, Quick Capture and Settings workflows.

## Windows v3.0.217
- New Desktop Setup and Portable from the current canonical frontend and approved identity.
- Same approved Themes, fonts, chapter atmospheres, backgrounds and visual structure.
- Includes per-binary SHA-256 sidecar, legacy updater-compatible EXE alias and AppBundle.

## Safety and compatibility
- Android Direct v0.2.5 must match the permanent Michel's Lab signer from v0.2.4 and have a higher versionCode. Existing debug-signed v0.2.2 customers need a backup before uninstall/reinstall.
- This public release is separate from Google Play and Microsoft Store submissions.
- Physical Galaxy IME/gesture checks, real Windows↔Galaxy provider-account sync and native locked-screen alarms remain separately tracked. The experimental Windows-installed WebView2 remote debugger evidence gate is not claimed green.
