# Michel's Life — Android Direct 0.2.10 + Windows 3.0.221

**Operación Granada · 11 de noviembre de 2026**

## Android Direct 0.2.10 (versionCode 12)
- Pomodoro Android bilingüe (español/inglés): duración, fases, controles, avisos, accesibilidad y cuenta regresiva en pantalla bloqueada.
- Conservar el valor de duración personalizado mientras el usuario escribe o cambia de idioma.
- Proteger los borradores de capítulos de Story: cada cuenta y el modo invitado conservan exclusivamente sus propios textos.
- Se mantienen la base de misiones, XP y el temporizador canónico; no se crea un segundo contador.
- APK Direct de actualización firmada con la **misma clave permanente** de la distribución 0.2.9. No uses la APK TEST/Debug para actualizar.
- Android 16 físico (incluido Galaxy) y la continuidad de cuentas reales no se verificaron con este build. Realiza copia de seguridad y confirma instalación conservando datos antes de abandonar la versión anterior; no desinstales para actualizar.

## Windows
Se incluye **Windows 3.0.221 sin cambios**, usando los mismos ejecutables y SHA-256 publicados y verificados en el release anterior. No se inventa una versión de escritorio nueva.

## Distribución
- APK Android Direct: `MichelsLife-Android-Direct-v0.2.10.apk`.
- Windows Setup y Portable: v3.0.221 sin cambios.
- Checksums SHA-256, manifest con procedencia de fuente, huella de certificado y archivos públicos verificados.

Android Direct no es una publicación en Google Play. Esta es la publicación estable de la rama Direct (no RC); el instalador del SO requiere autorización del usuario.
