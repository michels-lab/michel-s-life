# Michel's Life — Windows 3.0.222 + Android Direct 0.2.11

**Windows immersive Pomodoro, November 12, 2026. Stable unified distribution (no RC).**

## Windows 3.0.222 — fixed Pomodoro presentation

- During Work and Break, Pomodoro becomes a full-app immersive experience with a large timer over the selected existing Missions/Story wallpaper or themed scene.
- The old v3.0.162/v3.0.173 floating Focus dock and its sidebar stopwatch are **hidden on Windows**, including when a prior session is restored; there must never be a duplicate panel obscuring Missions or the Current Chapter.
- Explicit **Minimize** returns to Today, Missions, Story, Calendar and other sections with a compact running timer; reopen restores immersion. A deliberate minimize persists through a session reload and does not reset Focus.
- Focus sessions, task links, progress, cloud data, stats and XP remain handled by the existing `FocusStoryV30162` engine; no new timer owner or destructive data migration.
- Desktop application and installer both use version 3.0.222. Windows installer and portable app are built from the same immutable source revision and checked for successful startup; installer must also pass install, launch and uninstall smoke.
- `MichelsLife-Setup-v3.0.222.exe`: Windows installer, install over existing 3.0.221.
- `MichelsLife-Portable-v3.0.222.exe`: self-contained Windows portable app.
- `MichelsLife-v3.0.222.exe`: backward-compatible portable updater alias.

## Android Direct 0.2.11 — unchanged

- **Exactly the previously published production-signed Android APK 0.2.11, versionCode 13, and its signing certificate and manifest**, byte-for-byte unchanged.
- No Android 0.2.12, new Android signing key or new app data format.
- Users already running Android 0.2.11 do not need to reinstall it.

## Release verification

Windows source/desktop UI and Android UI checks on the exact release-intent commit, build and portable launch on Windows, installer install/relaunch/uninstall, Windows binary hashes, release artifact and title integrity, Android 0.2.11 original binary and certificate byte identity, new release provenance, immutable draft upload, downloaded checksum validation and final public status verification. No RC.

**Note:** An optional Windows Authenticode certificate is used only when provisioned; do not claim a signed Windows binary without certificate verification. Microsoft Store distribution is separate.

## Safe upgrade

For Windows, close Michel's Life and install the 3.0.222 setup over your existing version. Do not uninstall first. Backup your important progress before installing. The exact product-only release repository is `michels-lab/michel-s-life-releases`.
