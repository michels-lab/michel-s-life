# Michel’s Life — Windows 3.0.231 + Android Direct 0.2.20 (versionCode 22)

**Estable unificada — candidate source.** Solo es una versión pública cuando el repositorio oficial de descargas publique los **13 assets de origen coincidente** tras pruebas nativas y checksums; esta nota del código no prueba publicación.

## Corrige el problema de música clásica invisible

- La pantalla **Focus / Pomodoro** de Windows y Android muestra ahora la sección **Música clásica** y dos botones directos, **Mozart — Sonata K.545** y **Chaikovski — Oración matinal Op.39/1**, **sin abrir el menú oculto Audio**.
- Una pulsación reproduce el arreglo seleccionado, otra pulsación sobre el activo detiene la música; cambiar de compositor detiene el contexto anterior sin duplicar temporizadores.
- El botón muestra el estado reproducir/detener y el tema elegido persiste en el mismo motor canónico FocusStory que ya guarda la preferencia. Respeta idioma español/inglés.
- El antiguo selector avanzado de Audio conserva las ocho ambientaciones originales A+C, ambos temas clásicos y los siete tonos de fin de Pomodoro.
- **Alcance correcto de música:** son **fragmentos temáticos breves sintetizados directamente**, creados a partir de composiciones de dominio público. **No son piezas completas ni grabaciones de orquestas**. La futura integración de interpretaciones completas libres de derechos requiere fuentes sonoras autorizadas y pruebas de reproducción, no se declara resuelta por botones visibles.

## Requisitos de distribución

1. Los nueve workflows Source validation, UI smoke, Android UI smoke, Android Direct safe update discovery, Quick Mission y audio, Focus inmersivo, alarmas personales, Settings live colors, y música clásica deben aprobarse sobre el **mismo source release-intent commit aislado**.
2. Los scripts de UI deben abrir **ambas** superficies Focus, verificar que los botones de compositores aparecen directamente, pulsarlos, cambiar y detener, comprobar el estado guardado y detectar errores runtime reales de Chromium.
3. Windows Setup y Portable v3.0.231 deben compilarse, arrancar y tener SHA-256 válidos.
4. Android Direct v0.2.20 / code22 debe utilizar la **clave permanente de producción**, verificarse firma/huella, y la **APK firmada** debe instalarse y reabrirse en un Android 15 AVD con capturas reales y fail-closed. Los emuladores Android14/16 debug que pierdan QEMU/ADB son una incidencia aparte y **no** se marcarán aprobados.
5. Publicación atómica bajo un nuevo tag en destino como **13 assets**, comprobados también mediante descarga; sin RC ni Developer Edition.

**Aún abiertos:** aceptación física Windows/Galaxy de calidad de los arreglos, piezas completas, alarma Android con Doze/bloqueo/MP3 real, conservación del contenido local al actualizar, cuentas reales Supabase y Google, incidente JavaScript intermitente #168 y Store.
