# Michel's Life v3.0.216 — Windows

## New in this version
- The official **The Ascent** Michel's Life icon and lockup, with Michel Duarte / Michel's Lab identities in About.
- Quick Capture for Missions and Journal; a global `Ctrl + Shift + Space` shortcut.
- Windows tray integration, optional Start with Windows, Current Mission status and taskbar integration.
- `Ctrl + K` Command Palette, Sync Center, progressive startup, and automatic checks for available updates (installation remains a user action).
- Supabase sign-in and revision-aware synchronization client, with Google Drive available as a temporary manual migration/recovery fallback.
- Bilingual English/Spanish UI, with existing Themes, backgrounds, Current Chapter and other approved visual behavior retained.

## Before you enable cross-device sync
**Export a local backup of your existing Michel's Life data first.** Supabase functionality passed automated source/UI tests, but **real same-account Windows↔Android synchronization and conflict/restore on physical devices have not yet been verified**. Avoid treating a first upload, overwrite or restore as a safe migration of irreplaceable data without a backup.
