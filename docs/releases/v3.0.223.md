# Michel's Life — Windows 3.0.223 + Android Direct 0.2.12

**Versión final estable de Michel's Lab · 2026-11-12 · sin RC.**

## Mejoras y correcciones

- **Pomodoro Windows:** botón visible y operativo, vista inmersiva que conserva el fondo actual de Missions/Story y minimización deliberada sin duplicar el antiguo dock.
- **Alarmas programables Windows y Android:** una sola vez, todos los días o determinados días de la semana. Crear, editar, activar, desactivar, eliminar, posponer 5 minutos o descartar.
- **Pantalla de alarma:** vista inmersiva con fondo existente de Michel's Life, hora y título.
- **Android:** programación independiente con AlarmManager, recuperación tras reinicio, canal de notificación con sonido/vibración, pantalla bloqueada y permiso de superposición opcional para mostrar una alarma por encima de otras aplicaciones desbloqueadas.
- **Compatibilidad:** conserva la identidad de paquete `com.michelslab.michelslife`, certificado Direct permanente y datos actuales; nueva versión Android 0.2.12 (versionCode 14).
- **Español:** las etiquetas de accesibilidad de alarmas se actualizan cuando cambia el idioma.
- **Política de producto:** las ediciones Developer separadas fueron canceladas por instrucción del propietario en todos los productos Michel's Lab. No forman parte de esta entrega ni de los siguientes releases.

## Permisos Android y límites

Para avisos por encima de otras aplicaciones mientras el teléfono está desbloqueado, permitir **Mostrar sobre otras aplicaciones** en la configuración del sistema. Android puede solicitar también acceso a notificaciones, alarmas exactas y pantalla completa. Si estos permisos no están concedidos, la app conserva una notificación del sistema como alternativa, pero no asegura superposición ni puntualidad exacta bajo ahorro de batería/Doze. El sonido y vibración respetan los ajustes del dispositivo y el canal de alarmas.

En Windows, las alarmas suenan mientras Michel's Life está abierto; no se anuncia servicio de alarmas con la app cerrada.

## Evidencia

La distribución estable solo debe considerarse publicada cuando el pipeline compruebe build Windows + instalador/portable, APK Direct firmada con el certificado autorizado, verificaciones exact SHA, integridad SHA-256 y descarga real de la release pública. Las comprobaciones en emuladores no sustituyen la aceptación física del Galaxy de Michel.

**No instalar una APK de test/debug para reemplazar la edición Direct firmada.** Conserva el respaldo local y actualiza sin desinstalar la app actual.
