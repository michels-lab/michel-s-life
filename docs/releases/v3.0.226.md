# Michel's Life — Windows 3.0.226 + Android Direct 0.2.15

**Final stable release after the November 17 Operación Granada. No RC, Developer Edition, or unsigned debug APK.**

## New in this release

- **Open with Windows:** the first launch of the installed Michel's Life application registers the user-scope startup entry. The system tray provides a visible checkbox to opt out; the app respects that manual preference on future sessions.
- **Quick Alarm:** immediate one-time timers for +5, +10, +15, +30, +60, or +120 minutes. Actual deadlines are kept in milliseconds to avoid rounding a five-minute reminder to six minutes; Android schedules them with its native AlarmManager and respects notification/exact-alarm access.
- **Alarm ringtone options:** System default, Classic bell, Soft chime, Digital, Gentle sunrise and Pulse, selected per alarm. Play a preview and import an MP3, WAV, or OGG (maximum 6 MB). Files are saved locally in Windows IndexedDB and copied into Android app-private files via the system audio picker after validating size, type and header. This is one replaceable user-supplied custom sound; alarms set to My Audio use the currently imported file. The selected sound is used by the immersive Windows alarm and native Android alarm overlay or lock-screen Activity. Android's system notification channel may use the system alarm tone when full-screen/overlay access is unavailable.
- **Usable full-screen Pomodoro:** restores a large, readable clock, visible primary Start/Pause/Skip/Reset actions and an optional collapsed messages/affirmations section beneath the controls, in Windows and Android. The inert legacy Focus dock is hidden from the sidebar without altering the canonical FocusStory timer/session data.
- Preserves Chapter artwork and approved wallpapers, existing missions, journals, XP, recurring alarms, locked-screen focus notification policies, and Google Calendar per-mission write consent introduced previously.

## Provenance and release gates

- Windows: Setup, Portable and compatibility alias built from the exact source commit and executed in CI; SHA-256 sidecars.
- Android Direct: `MichelsLife-Android-Direct-v0.2.15.apk`, `versionCode 17`, package `com.michelslab.michelslife`, and **the existing permanent Direct certificate**; Play Store AAB is distinct and is not published by this release.
- Same public stable tag for Windows and Android, 13 assets including source-run provenance. The official release process must pass exact-source validation, real browser Windows/Android UI suites, updater safety, signing, Windows installed and portable launch, native installed Android15 signed APK launch/relaunch and public downloaded checksums before publishing; otherwise remain unissued or draft.
- Android 14/16 and real Galaxy device use, Doze/overlay permissions, real provider OAuth, persistence of an existing owner's data after in-place upgrade, and custom MP3 playback on the real lockscreen require owner acceptance and are not inferred from emulator tests. Intermittent Story/Pomodoro inline script issue #168 remains open.

**Upgrade:** preserve a backup of missions and journal before updating; do not uninstall the existing signed Direct APK. Android sound/notification permission settings can affect audible delivery.
